# 휴리스틱 금지 규칙 (v5, 2026-10-14 사용자 지시)

현재 챔피언 계열(E0003/D33/D45 → E0472 → E1022)에는 사람이 손으로 정한 구조·표현 결정이 많다. 이 스킬은 **그런 휴리스틱을 새로 만들거나, 기존 휴리스틱의 값을 바꿔 보는 행을 제안하지 않는다.** 대신 그 자리를 데이터에서 학습하는 구성요소로 바꾸는 행은 권장한다.

## 금지 범주와 챔피언 계열의 실제 예

| 범주 | 챔피언 계열의 예(이미 레시피에 있음) | 새로 제안하면 안 되는 형태 |
|---|---|---|
| (a) 고정 lag·rolling 창 | 27일 회귀 직관으로 지정한 26/27/28일 lag, rolling 통계 | "N일 전 값", "M시간 rolling 평균·분산" 같은 창·lag 상수를 사람이 정하는 특징 |
| (b) 임계값·공간 분할 요약 | coronal hole(CH) 특징: threshold 후 공간 요약해 XGB에 입력. SUVI 경도 strip 17개 | 영상·지도에 임계값을 걸어 면적·경계·비율을 뽑는 것, 경도·위도 strip·sector·bin으로 나누어 평균 내는 것 |
| (c) 시뮬레이션·고차원 출력의 수동 스칼라 요약 | WSA-Enlil field를 6개 스칼라로 요약 | ENLIL·PFSS·WSA·HUXt·자기장 지도 출력을 사람이 고른 몇 개 스칼라(도착 시각, 최대값, n_pending 류)로 줄이는 것 |
| (d) 리드 경계·구간 bin 수동 지정 | D33 horizon 경계 1–6 / 7–24 / 25–72h | 리드·도착 시각·속도·이벤트 구간을 사람이 정한 경계로 나누어 따로 모델링하거나 가중하는 것 |
| (e) 멤버·결합의 수동 선택 | E0003-line / D33-hsplit / D45-lvlmean 멤버 선택, per-horizon convex mixture, residual branch weight 0.2 | 멤버를 손으로 고르는 앙상블, 고정 가중·convex 가중 결합, 고정 계수로 branch를 더하는 것 |
| (f) analog·샘플링 설정 | analog residual 자체(“과거 오차가 반복된다” 가정), 96차원 상태 벡터, 차원 표준화·동일 weight, K=15, 이웃 uniform 평균, lookback 365일, 3시간 origin grid(00/03/06/…) | 사람이 정한 상태 벡터·거리·K·lookback·평균 방식의 analog/KNN, 사람이 정한 origin·시간 grid |

## 금지 형태
1. **새 휴리스틱 도입.** 위 범주에 해당하는 손으로 정한 lag·창·임계값·분할 수·요약 스칼라·경계·멤버·가중·K·lookback·grid를 새 변경으로 넣는 것.
2. **기존 휴리스틱 값 바꾸기.** 예: K 15→20, lookback 365→730, residual weight 0.2→0.3, strip 17→34, 경계 6/24h→12/36h, lag 27→27.27일, grid 3h→1h. 몇 개 값을 놓고 grid search·검증 창으로 고르는 것도 같은 금지다. 사람이 후보 값을 정하는 한 휴리스틱이다.
3. 위 두 가지를 다른 이름(“robust window”, “adaptive threshold” 등)으로 바꿔 쓴 것도 포함한다. 값이 학습 중 데이터로 정해지는지로 판단한다.

## 허용 형태
1. **학습형 대체 (권장).** 챔피언의 휴리스틱 하나를, 모델이 학습 중에 데이터로 정하는 구성요소로 바꾼다. 이것은 INCREMENT의 단일 변경으로 낼 수 있다.
   - (a) → 긴 원시 이력 위의 학습형 lag/temporal attention, 학습형 convolution·state-space 인코더.
   - (b) → SUVI/EUV 영상·자기장 지도를 학습형 인코더(CNN·ViT 등)로 직접 넣는 것. 임계값·strip 없이.
   - (c) → ENLIL·PFSS 출력 field를 학습형 encoder로 표현하는 것.
   - (d) → 리드를 연속 입력(embedding)으로 받는 단일 모델, 또는 학습되는 경계.
   - (e) → origin 상태를 입력으로 받는 학습형 gating·stacking(가중은 공식 창 이전 OOF에서 학습).
   - (f) → 학습형 metric·attention 기반 retrieval, 또는 analog 자체를 제거하는 것.
   - 학습형 대체의 하이퍼파라미터(층 수, 학습률 등)는 일반 모델 하이퍼파라미터로 보고 허용한다. 단, 구조·표현 결정이 다시 사람 손으로 돌아가면 안 된다.
2. **문헌에 정의된 표준 물리량.** 양성자 specific entropy, plasma beta, 동압, polytropic index처럼 문헌에 정의가 있는 양이다. `[휴리스틱 검사]`에 정의 출처를 인용한다. 계산에 창·상수가 필요하면 그 정의가 정한 값을 쓰거나 학습 파라미터로 둔다. 임의로 정한 창 길이·임계값·차수 절단·bin은 금지다.
3. **원시·고차원 입력을 학습형 표현으로 직접 넣는 것.** 예: ACE 원시 시계열, 영상 시퀀스, field.
4. 이미 챔피언 레시피에 있는 휴리스틱을 **그대로 두는 것**은 위반이 아니다. 단일 변경 행은 기준 레시피를 바꾸지 않는다.

## 행 작성 전 자가 점검 (모두 "아니오"이거나 출처가 있어야 쓴다)
1. 이 변경에 사람이 값을 정한 lag·창·임계값·분할 수·경계·K·lookback·가중·grid가 새로 들어가거나 바뀌는가?
2. 고차원 입력(영상·지도·시뮬레이션 field·원시 시계열)을 사람이 고른 스칼라나 구간 요약으로 줄이는가?
3. 들어가는 물리량이 문헌 정의가 아니라 이 행을 위해 만든 공식인가?

하나라도 "예"면 그 부분을 학습형 대체로 바꾸거나 후보를 버린다. 결과는 행의 `[휴리스틱 검사]` 칸에 적는다.
